# 게임숍 디스코드 봇 (가격표 + 거래내역)

## 1. 기능 요약

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/가격표` | 전체 상품 가격표 조회 | 전체 |
| `/가격추가` | 상품 등록 (이름, 가격, 카테고리, 재고) | 관리자 |
| `/가격수정` | 상품 가격/재고/카테고리 수정 | 관리자 |
| `/가격삭제` | 상품 삭제 | 관리자 |
| `/거래추가` | 거래 기록 (재고 자동 차감) | 관리자 |
| `/내거래내역` | 본인 거래 내역 조회 (최근 20건) | 전체 |
| `/전체거래내역` | 전체 거래 내역 조회 (필터 가능) | 관리자 |
| `/매출요약` | 총 매출, 인기 상품 TOP5 | 관리자 |

관리자 판단 기준: 서버 "관리자(Administrator)" 권한 보유자 **또는**
`.env`의 `ADMIN_ROLE_NAME`으로 지정한 역할(기본값: `관리자`) 보유자.

데이터는 `shop.db`(SQLite) 파일 하나에 전부 저장돼요. 별도 DB 서버가 필요 없어요.

---

## 2. 디스코드 봇 생성 (최초 1회)

1. https://discord.com/developers/applications 접속 → **New Application**
2. 좌측 **Bot** 메뉴 → **Reset Token**으로 토큰 발급 (이 값을 `.env`에 넣을 거예요)
3. 같은 Bot 메뉴에서 **Privileged Gateway Intents**는 전부 꺼둬도 됩니다 (이 봇은 슬래시 명령어만 사용)
4. 좌측 **OAuth2 → URL Generator**
   - SCOPES: `bot`, `applications.commands` 체크
   - BOT PERMISSIONS: `Send Messages`, `Embed Links`, `Use Slash Commands` 체크
   - 하단에 생성된 URL을 브라우저에 붙여넣어 원하는 서버에 봇 초대

## 3. 로컬(내 컴퓨터)에서 실행하기

```bash
# 1) 압축 풀고 폴더로 이동
cd discord-shop-bot

# 2) 가상환경 생성 (선택이지만 권장)
python -m venv venv
source venv/bin/activate      # Windows는 venv\Scripts\activate

# 3) 패키지 설치
pip install -r requirements.txt

# 4) 환경변수 파일 설정
cp .env.example .env
# .env 파일을 열어 DISCORD_TOKEN 값을 실제 토큰으로 교체

# 5) 실행
python bot.py
```

콘솔에 `✅ 로그인 완료: 봇이름` 이 뜨면 정상 작동 중이에요.
디스코드 서버에서 `/가격표`를 쳐보세요 (슬래시 명령어 동기화에 최대 1시간 걸릴 수 있지만
보통 몇 초~몇 분 내로 반영돼요).

## 4. 무료로 24시간 호스팅하기

컴퓨터를 계속 켜둘 수 없다면 아래 방법들을 고려해보세요. 무료 티어는 정책이
자주 바뀌니 신청 전에 최신 조건을 꼭 확인하세요.

### 옵션 A: Railway (추천, 가장 쉬움)
1. https://railway.app 가입 (GitHub 계정 연동 추천)
2. New Project → **Deploy from GitHub repo** (이 코드를 본인 GitHub 저장소에 올린 뒤 연결)
3. Variables 탭에서 `DISCORD_TOKEN`, `ADMIN_ROLE_NAME` 등 환경변수 등록
4. 자동으로 `pip install` + `python bot.py` 실행됨
5. 무료 크레딧 소진 후에는 소액 과금 필요 (월 몇 천원 수준) — 완전 무료는 아니지만 가장 간편함

### 옵션 B: Oracle Cloud Free Tier (완전 무료, 영구)
- 가입 시 평생 무료로 제공되는 VM(Always Free) 인스턴스에 봇을 올리는 방법
- 리눅스 서버 다루는 게 익숙하다면 가장 안정적인 완전 무료 옵션
- 설정 후 `tmux` 또는 `systemd` 서비스로 `python bot.py`를 상시 실행

### 옵션 C: Render.com
- Background Worker로 배포 가능, 무료 티어 있으나 일정 시간 후 슬립될 수 있어
  실시간 응답이 필요한 봇에는 다소 불리할 수 있음

> **주의**: Replit 무료 플랜은 봇이 자동으로 잠들기 때문에(예전에 쓰이던
> "UptimeRobot으로 깨우기" 편법은 현재 잘 작동하지 않아요) 추천하지 않아요.

가장 무난한 추천 순서: **Oracle Cloud Free Tier(완전 무료, 다소 설정 필요)** →
**Railway(설정 쉬움, 약간의 비용 발생 가능)**

## 5. 사용 예시 흐름

1. 관리자가 `/가격추가 상품명:롤 계정(브론즈) 가격:15000 카테고리:롤 재고:5`
2. 고객이 `/가격표`로 가격 확인
3. 거래 성사되면 관리자가 `/거래추가 구매자:@고객 상품명:롤 계정(브론즈) 수량:1`
   → 재고 자동 차감 + 거래 기록
4. 고객은 `/내거래내역`으로 본인 구매 이력 확인
5. 관리자는 `/매출요약`, `/전체거래내역`으로 전체 현황 파악

## 6. 커스터마이징 팁

- 카테고리별 이모지, 색상 등은 `bot.py`의 `embed = discord.Embed(...)` 부분에서 조정 가능
- 결제 자동화(토스/카카오페이 웹훅 연동)까지 원하면 별도 API 연동이 필요해요 — 필요하면 말씀해주세요
- 여러 서버(길드)에서 동시 사용 가능하도록 이미 `guild_id` 기준으로 데이터가 분리되어 있어요

## 7. 주의사항

- `.env` 파일(특히 토큰)은 절대 외부에 공유하거나 GitHub에 커밋하지 마세요
- 게임 계정/아이템 현금 거래는 게임사 약관 위반 소지가 있을 수 있으니, 취급 상품에 대한
  약관/법적 이슈는 별도로 확인하시길 권장해요
